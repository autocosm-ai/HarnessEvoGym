## 这份数据的已知缺陷

**Bug 1（SSE 半截未识别）** — 影响了这轮。`query()` 只要拿到非空正文就返回，
不检查是否收到 `[DONE]` 或 `finish_reason`。流在中途断开时，agent 会拿着被
截断的模型输出继续工作，交付质量下降。这不会报错，而是表现为"harness 能力差"。

方向：**当前分数是偏低的下界。**

混淆风险：截断概率与对话轮数正相关，效率低的 harness 触发更多截断。h0 效率
最低，可能被扣得最狠 —— 即 h0 与冠军的差距**有可能被此 bug 放大**。

**Bug 2（未完成题计入均值）** — 机制存在，但**未污染这一轮**：0 报错，
48 题全部真实完成打分。已产出均值都是有效数字。
